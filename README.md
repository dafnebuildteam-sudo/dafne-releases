# DAFNE desktop releases

This repository contains the official DAFNE desktop installers and update
manifests for macOS, Windows, and Linux.

## Download

Use the newest entry on the [Releases](../../releases/latest) page. Choose the
installer that matches your computer:

- macOS Apple Silicon: `mac-arm64.dmg`
- macOS Intel: `mac-x64.dmg`
- Windows 64-bit: `win-x64.exe`
- Linux: `linux-x86_64.AppImage` or `linux-amd64.deb`

Installed DAFNE desktop editions use the small `latest*.yml` manifests in each
release to check for updates. Organization records, credentials, photos, and
other workspace data are never stored in this repository.

The DAFNE application source is maintained in a separate private repository.
